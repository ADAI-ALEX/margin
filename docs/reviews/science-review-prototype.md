Reviewer: scientific-integrity reviewer. Date of review: 2026-11-14. Read-only audit.
Scope: `lib/engine/*`, `lib/schema/index.ts`, `design-exploration/data/build-snapshot.mjs`, the raw PSI cache, `snapshot.json`, `design-exploration/shared/content.ts`, `design-exploration/BRIEF.md`, and the concept code in `design-exploration/concept-{a,b,c}`, `app/**`.
Method: independent Python re-parse of every PSI CSV compared against `snapshot.json`; `vitest` run of the existing suite (12/12 pass); throw-away probe tests (kept outside the repo, in the session scratchpad) that call the real engine on the real snapshot; line-by-line comparison of `content.ts` with R3; grep lint over `app/**` and `design-exploration/**`.
Nothing in the repo was modified except this file.

Severity key: BLOCKER = must be resolved before any claim built on it is shown publicly or before the hero flow is declared to pass; MAJOR = materially misleading or non-compliant with a LOCKED rule, fix before production; MINOR = accuracy, wording or robustness issue.
"unverifiable locally" = the primary NASA paper is not in the workspace, so only R3's summary could be checked.

## 1. Executive summary

1. **The data pipeline is numerically sound.** 1,150 of 1,150 re-checked run rows (FLEX 274, CFI 87, CFI-G 179+154, Flame Design 207+120, BASS-II 129) match the raw CSV cells in column, unit and row, and Saffire I-III were checked by hand (13 rows). All conversion constants match the locked set. BASS-II uses the initial O2, and the impossible final-O2 values (40.4, 39.1) are flagged and never used. The counts reconcile exactly with Kickoff §H.2 once two artefacts are explained (861 trailing blank rows in the CFI-G inverse CSV; 8 non-run note rows in Saffire I/II).
2. **BLOCKER F-01: the Kickoff acceptance anchors do not reproduce at the locked defaults.** With published evidence on, Exploration Atmosphere is **DISTANT, D = 2.508** at the locked 10 cm/s preset flow (NEAR only if flow is 15-20 cm/s; the verdict flips at about 10.05 cm/s). Kickoff §H.4 and §H.10 require "NEAR or DIRECT". Artemis gives **2.03** at 10 cm/s and 0.36 at 20 cm/s, not SPEC's 0.15 (no transcribed T3 record has the 26.2% / 70.7 kPa pair SPEC used). The engine is arithmetically correct; the locked flow default and the 5 cm/s flow scale are what disagree with the spec's worked examples. This needs a product-owner decision, not a code tweak.
3. **BLOCKER F-02: "Smoke & detection" verdicts are built from non-smoke tests.** The lead's "O2 required to be placeable" gate removes all 117 SAME/SAME-R runs (none records O2), and the smoke hazard also admits every T1 solid run. Result: ISS + smoke = DIRECT, nearest = `PSI-25:r0100`, a PMMA-rod flammability burn with no smoke or detector measurement. Kickoff §C.5(a) allows only smoke-source runs plus Saffire smoke data (T3).
4. **MAJOR: partial matches can flip a verdict.** All 129 BASS-II runs have flow = null, so the nearest "PSI-only" run for ISS is a 2-axis match (D = 0.003, DIRECT) while the best fully compared run is Saffire-I at **D = 2.02 (NEAR)** at the 10 cm/s default. The robustness badge says "Robust" because it never varies this assumption. The copy "Comparable tests at these conditions" overstates it (F-03).
5. **MAJOR: limit points are treated as test conditions** (Olson & Ferkul ULOI*, BASS-II 13.5/15.4, LUCI at a fixed 20% O2). The Moon verdict's "nearest evidence" is the Ultem lunar ULOI* point (F-04).
6. **MAJOR: gas-burner O2 semantics.** For CFI-G and Flame Design **inverse** flames the XO2 column is the O2 fraction of the burner-fed oxidizer, while the chamber holds fuel/diluent. Plotting 85% on the same axis as a cabin atmosphere, and counting it in the ">45% O2" off-chart indicator, is the R3 §9 #16 failure mode. In addition, the "context only" list for materials contains all 660 CFI-G and Flame Design runs, where Kickoff §C.5(a) names only BRE (F-05, F-06).
7. **MAJOR: `nominal-stated` pressure for Saffire-II and III has no statement in the local sources.** R3 supports "cabin pressure" for BASS-II and Saffire-I only. The run `note` shows a paraphrase inside quotation marks. Physically defensible (about 100-101 kPa; at most 0.13 units), but it breaks Kickoff §C.3-6 / §H.3 as written until a quote is verified. It matters for one headline: Artemis PSI-only is DISTANT (2.70) with the nominal pressure and NEAR (2.15) without it (F-07).
8. **MAJOR: rankings are dominated by static metadata.** Under Moon scenarios, micro-g PSI investigations with zero in-regime runs (R = 40-45) outrank the only in-regime evidence (Olson & Ferkul, R = 34). Under EA, Saffire-III (no placeable run) outranks BASS-II. Kickoff §C.8 sanity assertions fail (BASS-II is not top 3 with published evidence; SAME-R is not top 2 for ISS + smoke) (F-08).
9. **Curated content (T3/T4) transcribes R3 faithfully.** All 36 Olson & Ferkul values, the seven Saffire IV-VI rows, FM2 and the atmospheres match R3 and Kickoff §C.6. The SPEC contradiction is confirmed: SPEC cites ICES-2024 for Saffire VI, while R3 and `content.ts` take the values from ICES-2026-577, and the two papers disagree on peak HRR (1.5-3.2 kW abstract versus 3.24 and 3.376 kW in the table) (F-10).
10. **Banned-claim lint: no hard violations.** Borderline items only: "conservative" quoted from NASA (`content.ts:199`), "not interpolated" outside the Method page (`EvidencePanels.tsx:89`). No gravity slider, no connecting paths between gravity levels, disclaimers present. SPEC's demo script still says "2,700 runs", which the Kickoff forbids (computed: 1,871 run rows, 1,129 placeable).

## Appendix A. Is `nominal-stated` 101.325 kPa defensible for BASS-II and Saffire I-III?

What the local sources say:
- **PSI record text (all five records):** no cabin-pressure statement. BASS-II: "oxygen varied below 21% by adding nitrogen" (working-volume vitiation) and a generic "(pressure, O2 concentration, temperature, etc.)". Saffire: "solid state sensors were used to measure pressure" (so pressure was measured in telemetry, but is not in the table). Kickoff §C.3-6 requires a statement in "the investigation's PSI text **or its primary paper**".
- **R3 (secondary):** BASS-II "at cabin pressure [S4]" (§1); Saffire-I "21.7% O2 (ISS reading), cabin pressure [S10]". Saffire-II is listed as "22.1% O2 [S10]" and Saffire-III as "air [S12]" with no pressure. Saffire IV is "22-23% O2, about 100 kPa" (980-1000 mbar in the S15 table), which supports about 100 kPa for the Cygnus cabin generally.
- Primary papers (NASA/TM-20210011385, ICES-2017, ICES-2021-266) are **unverifiable locally**.

Assessment:
- Physically plausible for all four: ISS/Cygnus cabin pressure is close to 100-101 kPa. A +/-3% error is 0.03 in ln P, which is 0.13 scale units, negligible against the 2.5 threshold in most cases.
- Procedurally defensible only for BASS-II and Saffire-I (R3 cites the paper). For Saffire-II and III the statement is an extension, and PSI-100 cites the wrong paper family. As written (`NOMINAL` map plus "quote not yet verified"), the run `note` presents a paraphrase in quotation marks. Kickoff §H.3 requires "each with a cited statement".
- Sensitivity (computed, `PSI_RUNS` with the nominal values nulled):

| Scenario (PSI-only, 10 cm/s) | With nominal pressure | Nominal pressure removed |
|---|---|---|
| ISS | DIRECT 0.003 | DIRECT 0.000 |
| Artemis | DISTANT 2.703 | **NEAR 2.150** |
| Exploration Atmosphere | DISTANT 6.455 | DISTANT 5.900 |
| Legacy 30% / 10.2 psia | DISTANT 4.230 | DISTANT 3.900 |

- The assumption is therefore not decisive for the EA hero, ISS or legacy rows, but it is decisive for the Artemis PSI-only verdict. Removing it makes the verdict more favourable (partial match).
- Recommendation: keep the assumption for BASS-II and Saffire-I with the verified quote; for Saffire-II/III either obtain the quote or set null; always show "nominal (stated), not measured" and the sensitivity note; do not let the Artemis verdict depend on it silently.
